# MedOpsis

AI-powered health-screening and education group project. This branch implements the text-chat backend only; Android, vision and voice are separate workstreams.

- [Backend setup](docs/setup.md)
- [Chat API contract](docs/api_documentation.md)
- [Design specification](docs/superpowers/specs/2026-11-19-medopsis-chat-design.md)
- [Handoff and historical context](docs/CHAT_HANDOFF.md)

The backend is not cleared for patient use. Project API credentials, actual app-token integration, a clinician-approved reference pack, native-language evaluation, provider data controls, consent, and deployment/privacy review remain prerequisites. Do not use the synthetic test fixture as clinical content.
